# Controller HTTP Contract Inventory

## Overview
This document records the complete HTTP contract audit across all 12 controllers and 67 route leaves wired in `apps/web/app/router.ts`.
It documents the authentication guards, authorization guards, structural and semantic status codes, RFC 9457 Problem Details content negotiation, browser HTML behaviors, and documented exemptions in compliance with Milestone M1 (Phases P1 & P2: Gate B).

## Summary of Gate B Guarantees Achieved
1. **P1.1 Canonical Guards & Response Trap**:
   - `requireAuth(context)` and `requireRole(context, allowedRoles)` implemented in `apps/web/app/actions/context.ts`.
   - Content negotiation: RFC 9457 `application/problem+json; charset=utf-8` on API requests (`Accept: application/json` or `application/problem+json`); 302 login redirect or HTML 403 on browser requests.
   - Response-trapping middleware installed in `apps/web/app/router.ts` catching thrown `Response` objects.
   - All 12 controllers migrated to canonical guards.

2. **P1.2 Unified HTTP Status Codes**:
   - `VALIDATION_FAILED` updated from 400 to 422 in `apps/web/app/actions/errors.ts`.
   - Semantic form validation failures across controllers re-render with `{ status: 422 }`.
   - Preserved intentional anti-enumeration 200 in `forgotPasswordSubmit` and 404 non-disclosure in `/surveys/:id`.

3. **P1.3 RFC 9457 Problem Details Content Negotiation**:
   - Eliminated raw plain-text error responses (`new Response('Forbidden', { status: 403 })`).
   - Standardized problem responses preserving `x-request-id` and `x-correlation-id` headers.

4. **P1.4 Shared Route Contract Consistency**:
   - Replaced all 56 hardcoded internal route string literals across controllers and middleware with `routes.<group>.<leaf>.href(...)`.
   - Preserved query parameter appending (`?returnTo=`, `?token=`).

5. **P2.1 Consolidated Session Assurance State**:
   - `AuthData` in `session-storage.ts` extended with `mfaVerifiedAt?: string`.
   - Eradicated all 10 duplicate top-level `session.set('stepUpAt', ...)` and `session.set('mfaVerifiedAt', ...)` writes across all controllers and helpers.
   - `session.get('auth')` is the sole authoritative container.

6. **P2.2 Controlled-Time Step-Up Expiry Testing**:
   - `isStepUpValid` in `apps/web/app/actions/utils.ts` enforces strict `< 10 * 60 * 1000` expiry (exactly 10m00s is expired).
   - Clock injection supported via `now?: number | Date | string | { request?: Request }` and `x-test-clock` request header.
   - Comprehensive zero-sleep unit test suite implemented in `apps/web/app/actions/utils.test.ts`.
